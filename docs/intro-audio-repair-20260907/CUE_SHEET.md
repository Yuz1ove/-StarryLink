# 22 秒配樂剪輯對照

採用 A Kind Of Hope 的 314–336 秒連續段落，影片時間 = 原曲時間 − 314。沒有重排樂句、改速、變更影片時長或鏡頭。

| 影片 | 既有畫面 | 同步音樂位置與編輯 |
| --- | --- | --- |
| 0–5 秒 | 海纜、連結 | 原曲 314–319 秒；0.4 秒淡入，直接進入既有鋼琴／弦樂樂句 |
| 5–8 秒 | 岸站、原路中斷 | 原曲 319–322 秒的和聲轉折，保留自然起伏 |
| 8–12 秒 | 空中中繼 | 原曲 322–326 秒，繼續完整樂句 |
| 12–16 秒 | 衛星近景 | 原曲 326–330 秒的尾句，向結尾和聲移動 |
| 16–22 秒 | 四域全景與品牌 | 原曲 330–336 秒終結和聲與自然延音；20.8–22 秒淡出 |

和聲位置由音高能量／原曲尾段結構分析輔助選取；是否符合「可靠、希望」及剪接落點是否自然，必須實際聆聽。`MUSIC_LISTENING_REVIEW=HUMAN_REVIEW_REQUIRED`。

母帶為來源 MP3 解碼後的 24-bit PCM WAV（48 kHz、stereo），不冒稱原作者無損錄音。發布 AAC 只編碼一次；影片使用 `-c:v copy`，AAC 直接 remux；試聽 M4A 與影片內音訊串流 hash 相同。

工作目標約 −18 LUFS、≤ −1 dBTP。採固定 −5.58 dB 增益，發布解碼結果 −18.02 LUFS、−6.60 dBTP。保留 14.30 LU 的自然起伏，未為了 loudnorm 的預設 LRA 11 而壓縮尾音。
